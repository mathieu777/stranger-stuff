Millbrook, novembre 1986. Les morts ont envahi la ville. Traverse cinq quartiers jusqu'à la station de radio pour appeler les secours.

Pour l'installer sur iPhone : touche Partager, puis « Sur l'écran d'accueil ».

Éclaire les zombies pour les figer. Dans chaque quartier, trouve le policier et l'orbe Nova.

Clavier : flèches pour marcher, espace pour la lampe, P pour la pause.
